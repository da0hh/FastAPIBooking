# 🏨 FastAPI Suggestions — AI-Powered Place Recommendation & Travelling Platform

Веб-приложение для поиска мест с интеллектуальными рекомендациями на основе предпочтений пользователя.

Пользователь выбирает **город** и **категорию места**, после чего описывает свои предпочтения в свободной форме. Система использует локальную LLM и векторный поиск для анализа запроса и подбора наиболее подходящих вариантов.

Проект объединяет **FastAPI backend**, **Streamlit frontend**, локальную AI-модель **Ollama** и векторную базу данных **Qdrant**.

### 🤖 AI-рекомендации

Пользователь может указать:

* Город
* Категорию места
* Свои предпочтения в свободной форме

После этого система выполняет поиск подходящих мест и формирует рекомендации с использованием AI.

Пример сценария:

```text
Город: Москва
Категория: Ресторан
Предпочтения: уютное место для ужина с хорошими отзывами
                    ↓
             AI + Vector Search
                    ↓
      Подходящие рестораны из базы
```

Для генерации рекомендаций используется локальная LLM через **Ollama**, а для семантического поиска — embeddings и **Qdrant**.

---

### 🔎 Семантический поиск

Вместо обычного поиска по точному совпадению текста система использует векторные представления данных.

Процесс поиска:

```text
Пользовательский запрос
        ↓
Создание embedding
        ↓
Qdrant Vector Search
        ↓
Поиск наиболее релевантных мест
        ↓
Передача найденных данных в LLM
        ↓
Формирование рекомендаций
```

Это позволяет находить подходящие варианты даже тогда, когда формулировка запроса пользователя отличается от описания места в базе.

## 🧠 AI Stack

### LLM

Для генерации AI-рекомендаций используется локальная модель:

```text
phi4-mini
```

Модель запускается через Ollama.

### Embeddings

Для преобразования текстовых описаний и пользовательских запросов в векторные представления используется:

```text
qllama/multilingual-e5-small
```

### Qdrant

Векторные представления хранятся в коллекции:

```text
places
```

Для поиска используется косинусная близость.

## ▶️ Запуск проекта

### Вариант 1 — Docker Compose

Клонировать репозиторий:

```bash
git clone https://github.com/da0hh/FastAPIBooking.git
cd FastAPIBooking
```

Запустить сервисы:

```bash
docker compose up --build
```

После запуска:

```text
FastAPI:
http://localhost:8100

FastAPI Swagger:
http://localhost:8100/docs

Streamlit:
http://localhost:8501

Qdrant:
http://localhost:6333

Ollama:
http://localhost:11434
```

---

### Вариант 2 — локальный запуск

Создать виртуальное окружение:

```bash
python -m venv venv
```

Активировать окружение.

#### Windows

```bash
venv\Scripts\activate
```

#### Linux / macOS

```bash
source venv/bin/activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Запустить FastAPI:

```bash
uvicorn main:app --reload --port 8100
```

Запустить Streamlit:

```bash
streamlit run app.py
```
